# Security policy

## Reporting a vulnerability

Please report vulnerabilities **privately** via GitHub Security Advisories:
<https://github.com/inflow-digital/amc/security/advisories/new>.
Do not open a public issue for security problems.

Include the AMC version (`amc --version`), your operating system and steps to reproduce.

## Supported versions

Security fixes are made on the latest release. Re-run the installer to upgrade.

## Security model

What AMC protects, how, and its known limitations (for example: a `full` access key can run
commands as your user and is not a sandbox) are described in
[docs/security.md](docs/security.md).
